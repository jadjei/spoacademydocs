# SPO Academy Documentation

Welcome to the internal documentation site for SPO Academy - a blockchain-enabled, project-based learning course designed to equip Stake Pool Operators with the business skills and frameworks needed to build viable, sustainable operations on Cardano.

## Project Overview

SPO Academy transforms technical stake pool operators into successful business operators through:

- **Project-Based Learning (PBL)** methodology
- **Business-focused curriculum** across 8 modules (000-700)
- **Andamio platform integration** for blockchain-verified credentials
- **Real-world scenarios** and practical applications
